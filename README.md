# Entre Páginas

## Sobre o projeto

**Entre Páginas** é um projeto de site para uma cafeteria-biblioteca fictícia. A proposta é apresentar um espaço que combina cafeteria e biblioteca, oferecendo um ambiente aconchegante para leitura, estudo, descanso e convivência.

O site apresenta informações sobre o conceito do estabelecimento, seu cardápio, algumas curiosidades e as vantagens oferecidas aos visitantes.

## Objetivo

O objetivo do projeto é criar uma página web simples, organizada e acessível, utilizando apenas **HTML e CSS**. O projeto também busca aplicar conceitos de estrutura semântica, responsividade e organização visual.

## Estrutura do projeto

```text
cafeteria_biblioteca/
├── index.html
└── style.css
```

* **index.html:** contém toda a estrutura e o conteúdo da página.
* **style.css:** contém os estilos visuais, cores, tipografia, espaçamentos e regras de responsividade.

## Tecnologias utilizadas

* **HTML5:** utilizado para estruturar o conteúdo da página de forma semântica.
* **CSS3:** utilizado para a estilização e adaptação do site para diferentes tamanhos de tela.

Não foram utilizados JavaScript ou outras linguagens de programação.

## Estrutura do site

O site é dividido nas seguintes partes:

* **Header:** apresenta o espaço para o logotipo, o nome da cafeteria e o menu de navegação.
* **Hero:** apresenta a proposta principal da cafeteria-biblioteca e uma imagem de destaque.
* **Cards:** apresentam o conceito, cardápio, curiosidades e vantagens do estabelecimento.
* **Seção de destaque:** reforça a proposta de oferecer um espaço para descanso e leitura.
* **Footer:** apresenta informações fictícias de contato e endereço.

A navegação utiliza **links internos com âncoras**, permitindo que o usuário seja direcionado diretamente para cada seção da página.

## Acessibilidade

Foram utilizados recursos básicos de acessibilidade, como:

* Elementos HTML semânticos, como `header`, `nav`, `main`, `section`, `article`, `figure` e `footer`.
* Atributos `alt` nas imagens.
* Hierarquia organizada de títulos (`h1`, `h2` e `h3`).
* Identificação da navegação principal com `aria-label`.
* Estados de foco visíveis para elementos interativos.
* Meta `viewport` para melhorar a visualização em dispositivos móveis.

## Design

A identidade visual utiliza uma paleta inspirada em ambientes de cafeterias e bibliotecas, composta por:

* Verde musgo;
* Bege;
* Creme;
* Marrom.

Os títulos utilizam uma fonte serifada para transmitir uma aparência mais clássica, enquanto os textos utilizam uma fonte sans-serif para facilitar a leitura.

As áreas e cards possuem bordas arredondadas e suaves. O projeto não utiliza `box-shadow`.

## Responsividade

O layout utiliza **CSS Grid, Flexbox e media queries** para se adaptar a diferentes tamanhos de tela.

Em telas menores, como celulares, os elementos são reorganizados em uma única coluna e o menu de navegação é ajustado para facilitar a utilização.

## Observação

O estabelecimento, endereço, telefone e demais informações apresentados no site são **fictícios** e foram criados exclusivamente para fins acadêmicos.

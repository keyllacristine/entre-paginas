## Prompts utilizados

### HTML
Crie um site em HTML semântico puro, sem CSS inline, apresentando uma cafeteria-biblioteca. O site deve possuir header com logo e texto, navegação com links internos, pelo menos três cards sobre conceito, cardápio, curiosidades e vantagens, espaços para imagens, hierarquia clara de títulos, acessibilidade com `alt` e footer com contato e endereço fictício. O site deve ser responsivo para desktop e mobile.

### CSS
Desenvolva o CSS do site utilizando verde musgo, bege, creme e marrom. Utilize fontes serifadas nos títulos e sans-serif no corpo do texto, com possibilidade de fontes gothic ou arredondadas. Utilize bordas suaves e arredondadas e não utilize `box-shadow`. O layout deve ser responsivo.

### Organização
Não utilize JavaScript ou outras linguagens além de HTML e CSS. Mantenha os arquivos HTML e CSS separados.

### README
Elabore um README.md simples explicando conceitualmente e tecnicamente o projeto, incluindo sua proposta, tecnologias utilizadas, estrutura dos arquivos, recursos implementados, acessibilidade e responsividade.
